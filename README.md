# FinDoc RAG: Banking & Regulatory Document Assistant

A Retrieval-Augmented Generation (RAG) assistant that answers questions about **RBI (Reserve Bank of India) circulars and Master Directions**. Every answer is grounded in the source documents, carries page-level citations, and the assistant explicitly refuses when the documents don't contain the answer.

## Highlights

- **Hybrid retrieval**: dense semantic search (FAISS + BGE embeddings) combined with BM25 keyword search via Reciprocal Rank Fusion (RRF).
- **Cross-encoder reranking** of fused candidates for higher precision at the top of the ranking.
- **Grounded generation** with `[Source N]` citations that map to document name, type, year and page number.
- **Explicit refusal rule**: out-of-scope or unanswerable questions return a fixed refusal message instead of a hallucinated answer.
- **Metadata-aware retrieval**: documents are tagged with `doc_type` and `year`, and queries can be filtered on them (regulations change, so recency matters).
- **Built-in evaluation harness**: Hit Rate@k, MRR, LLM-judged faithfulness, and out-of-scope refusal rate, plus an ablation across four retrieval strategies.

## Results

Evaluated on **7 RBI documents** (227 pages, 570 chunks) with **20 auto-generated test questions** (seed 42).

### Retrieval ablation

| Retrieval mode | Hit Rate@5 | MRR |
|---|:---:|:---:|
| Vector only | 0.90 | 0.800 |
| BM25 only | 0.90 | 0.783 |
| Hybrid (RRF) | 1.00 | 0.817 |
| **Hybrid + cross-encoder rerank** | **1.00** | **0.938** |

### Answer quality

| Metric | Result | Sample size |
|---|:---:|:---:|
| Faithfulness (LLM judge) | 1.00 | 10 questions |
| Out-of-scope refusal rate | 1.00 | 8 questions |

> **Note:** The test set is small and questions are synthetically generated by an LLM from sampled chunks, so these figures are indicative rather than definitive. Increase `N_EVAL` in the notebook for a more reliable estimate.

## Architecture

```
                 ┌───────────────┐
  RBI PDFs ───▶  │  PyPDFLoader  │ ──▶ page-level docs + metadata (doc_name, doc_type, year, page)
                 └───────────────┘
                         │
                         ▼
          RecursiveCharacterTextSplitter (1000 chars, 150 overlap)
                         │
              ┌──────────┴──────────┐
              ▼                     ▼
     FAISS (BGE-small)           BM25 index
      semantic top-30          keyword top-30
              └──────────┬──────────┘
                         ▼
             Reciprocal Rank Fusion (c=60)
                         ▼
        Cross-encoder rerank (MiniLM-L6) ──▶ top-5 chunks
                         ▼
        Grounded prompt ──▶ Groq LLM ──▶ cited answer / refusal
```

## Tech Stack

| Component | Choice |
|---|---|
| Orchestration | LangChain (LCEL) |
| Embeddings | `BAAI/bge-small-en-v1.5` (normalized) |
| Vector store | FAISS (CPU) |
| Keyword retrieval | BM25 (`rank_bm25`) with custom alphanumeric tokenizer |
| Reranker | `cross-encoder/ms-marco-MiniLM-L-6-v2` |
| LLM | `openai/gpt-oss-120b` served via Groq (`temperature=0`) |
| PDF parsing | `pypdf` |

## Getting Started

### Prerequisites

- Python 3.10+
- A free [Groq API key](https://console.groq.com/)
- RBI PDF documents (see above)

### Option 1: Google Colab (recommended)

1. Open `FinDoc_RAG_Assistant.ipynb` in Colab.
2. Add `GROQ_API_KEY` under **Secrets** (key icon in the left sidebar).
3. Run all cells and upload your PDFs when prompted in Section 4.

### Option 2: Local


## Usage

```python
# Default: hybrid retrieval + reranking
_ = ask("When must a bank classify a loan account as a non-performing asset?")

# Restrict to a document type and minimum year
_ = ask(
    "What governance requirements apply to technology risk?",
    doc_type="circular",
    min_year=2025,
)

# Compare retrieval strategies
_ = ask("What is the timeline for reporting fraud to the RBI?", mode="vector")
```

Supported `mode` values: `vector`, `bm25`, `hybrid`, `hybrid+rerank`.

Each call returns the answer plus a sources table:

| source | document | type | year | page |
|---|---|---|---|---|
| Source 1 | RBI Commercial Banks – Fraud Risk Management.pdf | circular | 2022 | 6 |

### Refusal behavior

```python
_ = ask("What is the current repo rate set by the RBI?")
# → "The provided documents do not contain enough information to answer this question."
```

## Configuration

All tunable parameters live at the top of the notebook:

| Parameter | Default | Description |
|---|---|---|
| `CHUNK_SIZE` | 1000 | Characters per chunk |
| `CHUNK_OVERLAP` | 150 | Overlap between chunks |
| `EMBED_MODEL` | `BAAI/bge-small-en-v1.5` | Embedding model |
| `RERANK_MODEL` | `cross-encoder/ms-marco-MiniLM-L-6-v2` | Cross-encoder |
| `LLM_MODEL` | `openai/gpt-oss-120b` | Generation model (Groq) |
| `FETCH_K` | 30 | Candidates pulled from each retriever |
| `TOP_K` | 5 | Chunks passed to the LLM |

Custom metadata can be set per file via `METADATA_OVERRIDES`:

```python
METADATA_OVERRIDES = {"my_circular.pdf": {"doc_type": "circular", "year": 2025}}
```

## Evaluation Methodology

| Metric | Description |
|---|---|
| **Hit Rate@k** | Whether the source chunk a question was generated from appears in the top-k results |
| **MRR** | Mean Reciprocal Rank of that source chunk (1.0 = always ranked first) |
| **Faithfulness** | An LLM judge checks that every claim in the answer is supported by the retrieved context |
| **Refusal rate** | Share of out-of-scope questions (trivia, recipes, coding, market predictions) correctly declined |

Test questions are generated by prompting the LLM with randomly sampled chunks (longer than 500 characters), so each question has a known ground-truth chunk.


## Limitations

- The corpus is small (7 documents); results may differ on larger or noisier collections.
- Evaluation questions are LLM-generated and the faithfulness judge is the same model family as the generator, which can bias scores upward.
- Hit Rate@k measures retrieval of one specific chunk, so semantically equivalent chunks elsewhere count as misses.
- Document year is inferred heuristically from the filename and first page; use `METADATA_OVERRIDES` for accuracy.
- This tool is for information and research purposes and is **not legal or compliance advice**. Always verify against the official RBI publications.
